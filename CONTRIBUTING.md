# Contributing to Robot For All

Thank you for helping make robotics education free for everyone.

## Ways to help
- **Lessons:** write or improve a lesson in `content/lessons/` (copy `p1-crank-01` as a starting point).
- **Translations:** fill in a language file in `content/i18n/`. Home languages matter as much as English.
- **Testing:** try the app on a low-end phone and report what's slow or confusing.
- **Code:** pick an issue labelled `good first issue`.

## Rules
1. Read `CLAUDE.md`. Its non-negotiables apply to everyone, not just Claude.
2. No feature without a spec in `docs/specs/`.
3. One change per pull request, with tests and a screenshot at 360 px wide.
4. Never add learners' personal information, photos or real names to examples, tests or issues.
5. AI-generated content is marked `ai_generated: true` and must be reviewed by a person before it's published.
