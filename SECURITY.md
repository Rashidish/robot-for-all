# Security and child safety

Robot For All is used by children. We treat security and privacy issues as urgent.

## Reporting
- **Do not** open a public issue for a vulnerability or a child-safety concern.
- Use GitHub's private vulnerability reporting ("Report a vulnerability" in the Security tab), or email: security@<domain> (set up once the domain is registered).
- We aim to acknowledge reports within 3 working days.

## Scope
The web app, back office, APIs, service worker, content pipeline and any AI features.

## Our commitments
- Collect the minimum personal data (POPIA).
- No third-party trackers or ads.
- No learner personal data sent to AI services.
- High and critical dependency findings block releases.
