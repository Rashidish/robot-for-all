## How it works

1. The **frame** (1) holds the axle.
2. The **washer** (2) is a thin, smooth ring on the axle.
3. The **wheel** (3) turns. When something pushes it sideways, it would rub on the rough card frame.
4. With the washer between them, the wheel rubs on something smooth instead, so it keeps turning freely and the frame doesn't wear. The axle (4) goes through all three.

## Try it

1. Push a card wheel on an axle hard against a card frame and spin it.
2. Put a straw slice between them and spin it again with the same push.
3. Which spins longer?
