## How it works

1. The **base** (1) stays still. It holds two pivots.
2. You move the **input** bar (2).
3. The **coupler** (3) carries the movement across.
4. The **output** bar (4) swings. Changing the length of any bar changes how far and which way the output moves. With four bars and four pivots this is a four-bar linkage.

## Try it

1. Join four strips with split pins to make a four-bar linkage, and pin the base strip to the table with Prestik.
2. Move the input bar. Draw the path of the coupler's middle point.
3. Make the output bar shorter. How does the movement change?
